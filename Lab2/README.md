# Software Engineering Lab 2

## Agile Backlog Creation and Sprint Simulation using Jira

This folder contains the documentation and screenshots for Software Engineering Lab 2.

### Project
Urban Rooftop Gardening Co-op App

### Activities
- Created Jira Epics and User Stories.
- Assigned priorities and story points.
- Organized the product backlog.
- Planned and simulated Scrum sprints.
- Tracked sprint progress using Jira boards.
- Generated Sprint Burndown and Burnup Reports.
- Analysed sprint progress and remaining work.
